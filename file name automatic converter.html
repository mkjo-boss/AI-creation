기본 : 문서종류_거래처명(법인회사는 주식회사 제외)_날짜

한 줄에 거래처명, 사업자등록번호, 대표자 순서로 적어주세요. 사업자등록번호가 있으면 상호 표기가 다르거나 스캔이 흐려도 번호만 맞으면 거래처가 확정되고, 대표자를 적어두면 개인사업자 계약서처럼 상호 없이 대표자 이름만 적힌 문서도 거래처명으로 바꿔 넣어요. 뒤 두 칸은 없으면 비워두셔도 됩니다.

시트 공유 설정을 바꾸지 않고 가져오는 방법이에요. 둘 중 편한 쪽을 쓰시면 됩니다.

방법 1 · 시트 파일을 여기에 끌어다 놓기 구글시트에서 파일 → 다운로드 → 쉼표로 구분된 값(.csv) 또는 Microsoft Excel(.xlsx)

방법 2 · 복사해서 붙여넣기 · 구글시트에서 거래처명이 있는 칸을 선택하고 Ctrl+C → 맨 위 입력칸에 Ctrl+V. 여러 열을 통째로 붙여넣어도 거래처명 열만 골라냅니다.

주소로 자동 연결하기 (공유 설정을 바꿀 수 있을 때만)

이 변환기는 서버 없이 브라우저에서만 동작해서 구글 로그인을 할 수 없어요. 그래서 액세스 권한이 있는 사용자만으로 제한된 시트는 주소로 읽어올 수 없습니다. 아래는 공유 설정을 바꿀 수 있는 경우에만 쓰세요.

준비 · 파일 → 공유 → 웹에 게시 → 형식을 .csv로 게시하거나, 공유 → 링크가 있는 모든 사용자 → 뷰어

주의 · 두 방법 모두 주소를 아는 사람은 누구나 시트를 볼 수 있게 됩니다.

표 형태 · 첫 줄에 거래처명(또는 상호·업체·회사·고객사·관여처) 머리글이 있으면 그 열을 읽고, 머리글이 없으면 첫 번째 열을 읽어요. 상호에 붙은 '주식회사'는 파일명에서 자동으로 빠집니다.
